Level 2: Patient Management System (PMS) & EHR Base
Goal: Hospital ke core data—yaani Patients aur unki electronic medical history—ko secure, fast, aur user-friendly tarike se manage karna.

Part A: Backend (NestJS + PostgreSQL/Prisma)
1. Database Schema Design (EHR & Patient Base)
Hamein Prisma mein naye models define karne honge jo relational database ke asoolon par kaam karein.

Patient Model: Isme medicalId (autogenerated custom string jaise PT-10293), firstName, lastName, cnic (unique), phone, dob, gender, bloodGroup, aur emergencyContact shamil hoga. cnic aur phone par indexing lagani hogi taake search milliseconds mein ho.

MedicalHistory (EHR) Model: Isme patientId (Foreign Key), allergies (Array ya JSON), notes, aur visitDate hogi.

Vitals Model: Har visit par BP, Heart Rate, Temperature track karne ke liye alag table jo MedicalHistory ya Patient se linked ho.

2. Patient CRUD & DTOs

Create Patient: CreatePatientDto banega jisme Zod ya class-validator ke zariye CNIC aur Phone ki strict formatting check hogi. Backend create hone par khud ek unique Medical ID assign karega.

Operations: PatientsController aur PatientsService banayenge jo naye endpoints (POST /patients, GET /patients/:id, etc.) ko handle karenge.

3. Search & Pagination Logic

Query Optimization: GET /patients API mein query parameters (?page=1&limit=10&search=0300) accept karenge.

Implementation: Prisma ki skip aur take properties use hongi pagination ke liye, aur where: { OR: [...] } use karke naam, phone, ya CNIC ke zariye fast searching implement ki jayegi.

Part B: Frontend (Next.js + Tailwind + Shadcn)
1. Multi-Step Registration Wizard

Lamba form user experience (UX) kharab karta hai. Hum isko 3 steps mein torenge:

Step 1: Personal Details (Name, DOB, CNIC).

Step 2: Medical Baseline (Blood Group, Allergies).

Step 3: Emergency Contact & Final Review.

Har step par react-hook-form aur Zod ke zariye real-time validation hogi taake user galat data ke sath aage na ja sake.

2. Patient Dashboard & Directory UI

Data Tables: @tanstack/react-table package integrate karenge jo modern React applications mein standard hai.

Features: Is table mein Global Search bar hoga, har column par sorting (A-Z) hogi, aur backend se aane wali pagination ko frontend pagination controls ke sath sync kiya jayega.

3. Patient Detail Profile View

Medical Card UI: Jab kisi patient par click kiya jaye, toh ek clean profile page khule ga jisme uski tasveer (placeholder), basic details, aur ek "Timeline" UI hogi jo purane visits dikhayegi.

Vitals Graph/Cards: Blood pressure aur temperature ki history ko cards ya chote charts ki shakal mein render karenge.

PDF Export: jspdf ya html2pdf.js library ka istemal karte hue ek "Download Report" button banayenge, jo screen par mojood data ko achi formatting ke sath PDF mein convert kar dega.
